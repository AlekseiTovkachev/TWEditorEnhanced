# Organize the editor around three game-aligned workspaces

The flat eleven-tab desktop layout made related features look disconnected and did not resemble the game's own information hierarchy. The redesigned interface uses a vertical rail with three game-icon destinations: Hero, Journal, and Inventory. The exact face, scroll, and hand glyphs are resolved at runtime from the installed game's shared `gui_panel3` atlas; Journal's secondary tabs remain text-only. Hero contains a compact character and Difficulty summary plus Attributes, Signs, and combat-style pages; Journal mirrors the game's eight journal sections; Inventory combines Equipment, Satchel, Alchemy Sack, Quest Items, and the non-spatial Storage list. Statistics remains implemented but is hidden from the GUI.

Standard file and save operations remain conventional desktop commands so their meaning is unambiguous. Content uses a restrained, dark Witcher-inspired design, loads game artwork from the user's installation rather than bundling it, and reflows its major regions for resizing and display scaling. The accepted Inventory direction follows the game's broad composition: long Storage list on the left, the exact 12 supported Equipment slots in game-like spatial placement at center, and carried containers on the right. Each container has one Add action; capacity counters are omitted; Storage search opens from a magnifier; compatible Equipment targets accept drag-and-drop with invalid drops making no change.
