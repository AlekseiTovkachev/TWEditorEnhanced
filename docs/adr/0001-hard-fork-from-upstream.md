# Hard-fork from upstream

This repo started as a fork of `boazy/TWEditorEnhanced` and has already diverged (package renamed to `app.tweditor`, difficulty support, encoding fixes). We decided to treat it as an independent project: no upstream syncing, independent versioning (4.x), and all issues/specs live in this repo's tracker. The planned modernization (Java 25, Gradle 9, jpackage, FlatLaf) would never merge upstream cleanly, so staying syncable has no pay-off.
